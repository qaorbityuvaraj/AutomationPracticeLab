    PLAYGROUND / BROWSER EVENTS

    Dialogs & Alerts

    Practice handling browser-native alert, confirm, and prompt dialogs with reliable Playwright event patterns.

    NATIVE BROWSER DIALOGS

    These dialogs block page interaction until handled. In Playwright, register the dialog listener before the click that opens it.

    A. Simple alert

    Alerts have one outcome: accept.

    ALERT
    Trigger and accept the alert.
    Playwright Pythonpage.once("dialog", lambda dialog: dialog.accept())
    page.get_by_role("button", name="Trigger Alert").click()

    B. Confirmation dialog

    Choose OK to accept or Cancel to dismiss.

    CONFIRM
    Choose OK or Cancel in the confirmation dialog.
    Playwright Pythonpage.once("dialog", lambda dialog: dialog.accept())
    # Or: page.once("dialog", lambda dialog: dialog.dismiss())

    C. Prompt dialog

    Enter a name, accept it, or dismiss the prompt.

    PROMPT
    Enter a value or dismiss the prompt.
    Playwright Pythonpage.once("dialog", lambda dialog: dialog.accept("Asha"))
    page.get_by_role("button", name="Trigger Prompt").click()

    D. Dialog event handling

    Read dialog type and message before deciding how to handle it.

    EVENTS
    def handle_dialog(dialog):
      print(dialog.type, dialog.message)
      if dialog.type == "confirm":
        dialog.dismiss()
      else:
        dialog.accept()

    page.once("dialog", handle_dialog)
    page.get_by_role("button", name="Trigger Confirmation").click()

    Use once() for a single expected dialog. Long-lived listeners should be managed carefully so they do not handle a later dialog unexpectedly.

    E. Delayed dialog

    The dialog opens after a short delay—no fixed sleep needed.

    DELAYED
    Start the delayed dialog, then accept it.
    Playwright Pythonwith page.expect_event("dialog") as dialog_info:
      page.get_by_role("button", name="Trigger Delayed Alert").click()
    dialog_info.value.accept()

    Browser dialog reminder

    Native dialogs are not DOM modals.

    TIP
    • alert() must be accepted.
    • confirm() returns True or False.
    • prompt() returns entered text or None.
    • Register listeners before the triggering action.
