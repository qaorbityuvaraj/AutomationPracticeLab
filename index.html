    PRACTICE MISSION

    Dropdown challenges

    Hints and solutions stay collapsed
    1. Select Java using the label locator.

    Use the native programming language select.

    page.get_by_label("Select Programming Language").select_option(label="Java")
    2. Select Python using its value.

    Use the option value rather than its visible text.

    page.locator("#language-select").select_option("python")
    3. Select three testing tools in the multiselect.

    Use the Testing Tools control and validate the selected count.

    page.get_by_label("Select Testing Tools").select_option(["selenium", "playwright", "cypress"])
    4. Select Linux from the custom dropdown.

    Open the button first; this is not a native select.

    page.get_by_role("button", name="Choose an operating system").click()
    5. Search and select Japan.

    Filter the country options before choosing the matching option.

    page.get_by_label("Search country options").fill("Japan")
    6. Hover over the menu and click Settings.

    Confirm the menu item is visible after hovering.

    page.get_by_role("button", name="Open hover menu").hover()
    7. Select India → Tamil Nadu → Chennai.

    Observe how State and City are enabled.

    page.get_by_label("Country").select_option("india")
    8. Select QA and verify Production is disabled.

    Inspect the native Environment select’s options.

    page.locator("#environment-select option[value='production']").is_disabled()
    9. Locate the dynamic dropdown without using its changing ID.

    Use the stable test ID, name, or label.

    page.get_by_test_id("dynamic-dropdown")
